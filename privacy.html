Privacy Policy

Last updated: November 9, 2026

eloy-youtube is a personal tool used only by its owner to manage his own YouTube channels.

Data accessed

With the owner's permission, the app uses Google OAuth to access the YouTube Data API for the owner's own channels: uploading videos, editing titles, descriptions, tags, thumbnails and publication settings, and reading channel and video information.

How data is used and stored

Data is used only to perform these actions. OAuth tokens are stored locally on the owner's computer. No data is sold, shared with third parties, or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
